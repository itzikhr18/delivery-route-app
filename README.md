# מסלול משלוחים

אפליקציית Web/PWA בעברית לתכנון מסלול משלוחים יומי. האפליקציה מקבלת כתובת התחלה ורשימת כתובות משלוח, ממירה אותן לנקודות על מפה, מחשבת סדר עצירות מומלץ ומאפשרת ניווט לכל עצירה.

## יכולות עיקריות

- הזנת כתובת התחלה וכתובות משלוחים.
- ייבוא מהיר של רשימת כתובות בהעתק/הדבק.
- חישוב מסלול אופטימלי באמצעות OSRM.
- המרת כתובות בישראל לקואורדינטות באמצעות Nominatim.
- מפה אינטראקטיבית עם Leaflet ו־OpenStreetMap.
- גרירת סמנים לתיקון מיקום ושמירת תיקונים מקומית.
- פתיחת ניווט ב־Waze עם fallback ל־Google Maps.
- סימון משלוח כבוצע עם אפשרות ביטול.
- היסטוריית משלוחים מקומית ל־30 יום.
- תמיכת PWA בסיסית להתקנה ושימוש עם cache מקומי.

## הרצה מקומית

הפרויקט סטטי ואינו דורש build או התקנת חבילות.

```bash
npm start
```

ב־PowerShell ב־Windows ייתכן שצריך להריץ:

```bash
npm.cmd start
```

לאחר מכן לפתוח בדפדפן:

```text
http://localhost:8000
```

אפשר גם להריץ ישירות:

```bash
node dev-server.js
```

או להשתמש בכל שרת סטטי אחר. מומלץ לא לפתוח את `index.html` ישירות כקובץ, כי Service Worker ו־PWA עובדים נכון יותר דרך HTTP.

## קבצים מרכזיים

- `index.html` - מבנה המסכים, CSS והטעינה של Leaflet והאפליקציה.
- `app.js` - מצב האפליקציה, גיאוקודינג, חישוב מסלול, מפה, היסטוריה ואירועי UI.
- `manifest.json` - הגדרת PWA, שם, אייקונים ותצוגת standalone.
- `sw.js` - Service Worker לקאש של קבצי האפליקציה.
- `dev-server.js` - שרת סטטי מקומי לפיתוח ללא תלות חיצונית.
- `icons/` - אייקונים להתקנה למסך הבית.

## שירותים חיצוניים

האפליקציה משתמשת בשירותים ציבוריים:

- Nominatim עבור חיפוש כתובות.
- OSRM עבור חישוב מסלול נהיגה.
- OpenStreetMap tiles עבור המפה.
- Waze ו־Google Maps עבור ניווט.

השירותים הציבוריים מתאימים לשימוש קל ולבדיקות, אבל באפליקציית עבודה יומיומית כדאי לשקול ספק מפות ייעודי עם מפתח API, מכסות ותנאי שימוש מסודרים.

## Debug

כדי לראות לוגים בדפדפן, לפתוח את האפליקציה עם:

```text
?debug
```

לדוגמה:

```text
http://localhost:8000/?debug
```

## הערות פיתוח

- הנתונים נשמרים ב־`localStorage` בלבד.
- אין כרגע backend, משתמשים, סנכרון בין מכשירים או בדיקות אוטומטיות.
- בכל שינוי בקבצים שמוגשים דרך ה־Service Worker יש לעדכן את `CACHE_NAME` ב־`sw.js`, כדי שמשתמשים יקבלו את הגרסה החדשה.
